# Proyecto desarrollado para el curso de Programación Avanzada.
Tema: Sistema Académico de Avance Curricular.

Instrucciones de Instalación y Ejecución
1. Requisitos Previos
Para ejecutar este sistema, asegúrate de tener instalado:

Java JDK: Versión 17 o superior.

IDE Recomendado: NetBeans, IntelliJ IDEA o Eclipse (opcional, pero facilita la lectura del código).

Sistema Operativo: Windows, macOS o Linux.

2. Estructura de Archivos:
El proyecto utiliza persistencia en modo batch, por lo que requiere que los siguientes archivos .txt estén en la raíz del proyecto (en la misma carpeta donde se ejecuta el programa) para funcionar correctamente:

alumnos.txt: Registro de estudiantes.

profesores.txt: Registro de docentes.

asignaturas_alumnos.txt: Relación de materias y notas.

asignaturas_profesores.txt: Relación de materias dictadas.

3. Instalación:
Descarga o clona el repositorio/carpeta del proyecto.

Abre tu terminal o consola de comandos.

Navega hasta la carpeta src o donde se encuentren los archivos .java.

4. Instrucciones de Uso:
Al iniciar, el sistema presentará un cuadro de diálogo para elegir el modo de interfaz:

Modo Consola: Ideal para depuración y visualización rápida de datos en texto.

Modo Ventana: Interfaz gráfica basada en JOptionPane para una gestión más intuitiva.

Funcionalidades principales:
Gestión de Alumnos: Permite agregar, buscar y ver el progreso curricular (SIA-9).

Gestión de Profesores: Permite asignar asignaturas y buscar por especialidad.

Se recomienda salir usando la opción "Salir" del menú.
